# YandexScooter API Tests
Тестирование API ЯндексСамоката по [документации](https://qa-scooter.praktikum-services.ru/docs/)

Были выполнены проверки по следующим сценариям:

#### [Создание курьера](tests/test_create_courier.py)
- Успешное создание курьера
- Ошибка при попытке создать дубликат курьера
- Ошибка при отсутствии обязательного поля
- Ошибка при создании курьера с уже существующим логином

#### [Логин курьера](tests/test_login_courier.py)
- Успешная авторизация курьера
- Ошибка при авторизации с неверными данными
- Ошибка при авторизации без обязательных полей

#### [Создание заказа](tests/test_create_order.py)
- Создание заказа с разными вариантами поля color: BLACK, GREY, оба цвета сразу, тело без поля color

#### [Список заказов](tests/test_orders_list.py)
- Успешное получение списка заказов

### Команды
Установить зависимости
``` shell
pip3 install -r requirements.txt
```
Запустить все тесты
```shell
pytest tests/
```
Посмотреть отчет в формате веб-страницы
``` shell
allure serve allure_results
```
